# 契約ファイル

`spec-types.ts`は詳細仕様v1.0の5つのTypeScriptブロックを結合した型契約である。`adapter-contracts.ts`は実装を分離する境界の提案を具体化したもの。どちらも同期処理の実装ではない。

これらの型がコンパイルできても、受信JSONが正しいこと、ファイル操作が原子的であること、APIが実在・動作することは証明しない。実装時に必ず実行時検証と契約試験を作る。

`LocalStore.scanComplete()`の不在判定は、この配列だけを根拠にせず、仕様どおり個別確認・対象外・読取失敗と照合する。未読ファイルを捨てて成功する実装は禁止。

`ClientStore`の初回作成、レシートの細部、予算、内部保存は詳細仕様と実装決定書に従い追加する。未定のSDK型を模倣して実APIの代わりにしない。
